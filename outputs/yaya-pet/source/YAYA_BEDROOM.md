# 芽芽的卧室：从动作片段到连续生活

卧室沿用现有芽芽的身体、叶子、表情和两只真实的短胳膊。房间提供固定的位置和物品；芽芽先走到物品旁，再接触、使用、放回。不能靠切换背景、生成另一件道具或突然变长的手臂掩盖缺少的过程。

这份文档描述保留的二维侧床卧室样例。当前首页已升级为六空间的小家与右侧工作台，见 [YAYA_HOME.md](YAYA_HOME.md) 与 [YAYA_WORKBENCH.md](YAYA_WORKBENCH.md)。旧版 `gallery.html#life-panel` 继续嵌入 `bedroom.html`；旧花园保留在同页的 `#garden-life-panel`，默认关闭自主活动并暂停播放。也可单独打开 `bedroom.html` 检查这些历史动作，画布和物件热点会随页面宽度缩放。

## 场景与坐标

设计画布为 1920 × 1080，角色一个身体单位为 28 像素。左侧低床、中间地毯、右侧低书架保持固定位置，前方留出行走通道。房间物件应该看上去便于这个小身体使用：可拿取层低于芽芽的眼睛，上床不需要一次跨过整个床垫。

视觉布局与热点范围在 `src/yaya-bedroom-art.js` 的 `layout` 中：床以 `(425,790)` 为基准，床垫上沿 `y=752.2`；低柜上的绘本位于 `(1415,625)`，泰迪熊位于 `(1600,625)`；床头灯拉绳握点位于 `(206,659)`。行走先进入 `y=905` 附近的前方过道，再走近物品，避免沿斜线穿过床或柜子。房间素材没有独立缩放角色，各处使用同一个 `u=28`。

| 物件 | 用途 | 必须保持的关系 |
| --- | --- | --- |
| 低床、枕头、被子 | 上床、仰卧、呼吸、起床 | 枕头托住后脑，侧脸朝向上方，被子覆盖身体 |
| 低书架和绘本 | 选书、取书、阅读、翻页、还书 | 同一本书从书架移动到手里，再回到原位置 |
| 泰迪熊和收纳位置 | 取出、抱一会儿、放回 | 熊只存在一份；握持由真实手掌驱动 |
| 地毯与地面 | 安静站立、散步、停留 | 脚落在地面，转向时脸与身体同步 |

## 一个行为需要完整过程

| 行为 | 动作顺序 | 结束状态 |
| --- | --- | --- |
| 看绘本 | 看向书架 → 走近 → 伸手接触书 → 拿起 → 阅读、翻页 → 合上 → 放回 → 收手 | 书回到书架，芽芽恢复短手待机 |
| 抱小熊 | 朝玩偶走近 → 手接触 → 拿起 → 轻抱、停留 → 放回 → 收手 | 熊回原位，没有额外副本 |
| 睡个小觉 | 走到床旁 → 转向床 → 碰床沿 → 小脚蹬上低床 → 坐稳 → 仰卧 → 盖被 → 入睡 | 身体由床支撑，脸朝天花板 |
| 起床 | 睁眼 → 掀开被子 → 起身坐稳 → 下床 → 双脚落地 → 舒展 | 角色重新站在地面，被子仍属于床 |
| 自己待一会儿 | 观察 → 慢慢走向空处 → 站稳 → 呼吸、眨眼 | 不强行接另一个高能量动作 |

每个阶段都需要可见的准备和收尾。翻页必须能看出纸页变化；还书应先把书放回支撑面，再松手。这里的“自主”表示角色能够选择经过设计的完整行为，不能把不相关动画每隔几秒随机拼接。

阅读时左手承托绘本，右手从书角向内、向上拨动，纸页同步翻过；整本书保持在左手支撑的位置，不随右手一起滑动。抱熊时两只手轻轻收拢，身体微微靠一下，再恢复原位。动作幅度保持小巧，生命感来自动作目的与接触，而不是整只角色不停震动。

## 共用骨架与握持

`YayaViews.draw` 是唯一的角色绘制入口。角色在房间中的位置、朝向、坐姿和手部目标由卧室控制器提供；身体轮廓、面部、叶子和手臂仍由已有模块负责。不要为卧室另画第二套芽芽，也不要调用会自己生成道具的旧动作后，再叠一套房间道具。

肩根固定在角色坐标 `±2.28, -3.93`，对应腮红高度。圆掌半径 `.64`，日常胳膊长度 `1.27`，最大伸手长度 `2.05`。普通站立、转向和等待优先改变胳膊方向；确实伸手拿物时才使用更大长度。超出范围时应让身体先走近，而不是延长胳膊。

绘制顺序遵循：后侧手臂 → 身体 → 前侧手臂 → 手持物 → 真实圆掌。遮挡身体的桌面或被子也需要明确层次。圆手是已有手臂的末端，不增加线条胳膊或另一对悬浮手。

道具握持必须使用求解后的 `arm.sockets.grip`。求解器会限制可达距离，因此 `requested` 目标不等于真正手掌位置。直接用请求目标绘制书或熊，会在长距离伸手时出现脱手。侧身时，目标还需经过同一投影和角色变换，不能混用正面局部坐标与房间像素坐标。

平常双手搬运以两个实际手掌的中点支撑物品；翻页是例外，此时 `propLocal` 以左手加固定书脊偏移作为支点，右手可以自由拨页。不要把所有“物品在两只手之间”的动作都机械地绑定到双掌平均，否则移动一只手就会拖走整件物品。肩根和最大臂长不随这种支撑关系改变。

`YayaViews.draw` 的 `view.projectedArmTargets` 接受按手的 `-1`、`1` 编号给出的投影平面目标，在原有体积投影后交给同一个求解器。这个接口不会改变肩根。默认将指定手放在身体前方；`projectedHandsForeground:false` 可以让转背后的握持被身体遮挡。`hideProps` 关闭基础动作自带道具，`drawProps` 优先绘制卧室持有物；`hideFeet` 用于被子后的足部遮挡。返回的手掌仍在角色局部平面中，房间根据同一个位置、旋转和呼吸缩放得到世界握点。

## 所属关系与连续性

同一件道具在任意时刻只有一个所属状态：`房间支撑面`、`真实手掌` 或 `正在放置`。拿取前道具留在家具上，手移动到它；接触成立后，道具才随手移动。放回时按相反顺序，先接触支撑面，再收手。状态切换前后道具的世界位置必须相同。

对睡姿，继续使用已确认的侧脸仰卧关系：`yaw = 1.28`，整体 `rotation = -π/2`。其面部朝向的竖直分量为负，即屏幕上方。旋转角色的同时，床、枕头和被子保持在房间中；不要把床跟着角色旋转，也不要把仰卧画成正面贴图向旁边倾倒。

行走使用实际移动距离推进脚步。角色转向时，眼睛、嘴和身体共用朝向，不加眼睛惯性；叶子可以保留柔软的跟随。接近目标应减速，停稳后再伸手，避免一边滑行一边拿东西。

## 验收点

- 抽样每个动作的阶段交界，身体与道具位置不跳变，朝向沿最短合理路径变化。
- 握持阶段，物件握点与求解后的手掌位置一致；放回后，物件支撑点与家具表面一致。
- 任意时刻只有两个手掌、一个正在使用的绘本或泰迪熊，没有旧姿势遗留的侧手。
- 肩根不迁移；手臂不超过最大可达范围，普通休息姿势保持日常长度。
- 睡眠时床、枕头、被子都在；侧脸朝上、手藏在被子下，呼吸不让身体漂离床垫。
- 暂停后房间、角色和行为时钟都停止；切到后台不累计补播；恢复时从同一状态继续。
- 手动请求在安全阶段接管，已经拿起的物件先放回或继续持有，不能直接消失。
- 同时检查正面、侧面以及靠近家具时的遮挡，几何检查通过后仍需看实际画面。

## 模块与调用

| 模块 | 职责 |
| --- | --- |
| `yaya-bedroom-art.js` | 固定房间、家具、绘本、泰迪熊、床上被子和热点布局 |
| `yaya-bedroom-model.js` | 行走路径、阶段队列、握持所属、行为完成、安全接受下一个请求 |
| `yaya-bedroom.js` | 将房间状态交给同一个角色骨架与房间绘制，处理遮挡 |
| `yaya-bedroom-ui.js` | 播放暂停、点击房间物品、自动活动开关、后台暂停 |

```js
const room = YayaBedroomModel.create({ auto: true });
room.request('read');
room.step(1 / 60);
const state = room.getState();
// position / yaw / motion 是身体状态。
// handTargets / grips 是真实手的位置；grips[].world 是世界坐标。
// carrying 和 props.book / props.teddy 共同说明物品所属。
// pending 是等待安全交接的下一个用户请求。
```

房间命令是 `window`、`read`、`teddy`、`tidy`、`lamp`、`sleep`、`wander`。`tidy` 在物品已经各归原位时是查看整理结果，不会为了播放“收拾”动画先制造一地乱物。阅读和抱熊本身包含物品放回流程。自动活动在完整行为后留出安静时间，并避免短期重复。此版是可持续运行的卧室原型，自动调度尚未连接饥饿、疲劳等需求；不能将它描述为已经具备全天作息系统。

`setAuto(false)` 停止自主选择下一件事，但允许正在做的事收尾；界面的暂停才停止整个行为时钟。UI 的 `yayaBedroom.advance(seconds)` 是验证和截图用的确定性步进，它仍调用同一个模型，不提供瞬移到目标姿势的捷径。

运行 `node test-yaya-bedroom.mjs` 检查完整行为、短臂可达、物体所属、握持交接、坐卧连续性与安全中断；加 `--browser` 检查实际页面加载、物体按钮、手动请求排队、暂停、移动端宽度、旧 `gallery.html` 嵌入和绘制输出。`test-yaya-life-page.mjs` 同样在旧图库保留花园验证，会先显式开启花园再检查其行为流程。几何检查不代替画面审查。动作目录应区分房间行为与原有四秒基础动作，不能把基础动画的时长直接当作完整生活过程。
